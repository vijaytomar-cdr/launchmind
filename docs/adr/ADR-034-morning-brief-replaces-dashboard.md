# ADR-034: Morning Brief Replaces Dashboard

**Status:** Accepted  
**Date:** 2026-07-08  
**Milestone:** 07 — Owner Experience

---

## Context

The existing `/dashboard` page is a KPI dashboard (391 lines). It shows metrics, products, latest brief, and channel performance. Founders see numbers without interpretation. This is the first screen they land on after login.

---

## Decision

### `/dashboard` redirects to `/dashboard/brief`

The Morning Brief becomes the primary landing page for authenticated founders.

```
GET /dashboard → redirect → /dashboard/brief
```

The existing `/dashboard` KPI view is not deleted — its data is incorporated into Results (`/dashboard/results`) and the Morning Brief itself.

### Morning Brief is an AI recommendation, not a metrics report

Structure:
1. **Greeting** — personalized time-of-day + product context
2. **Primary recommendation** — ONE thing to focus on, generated by Haiku using Context Engine
3. **Why** — evidence chips (max 3), confidence score
4. **Top 3 opportunities** — from `saved_opportunities` table
5. **Pending approvals** — count + mini-list, links to `/dashboard/approvals`
6. **Recent timeline** — last 5 events
7. **Growth Brain status** — has strategy / confidence / last updated
8. **Ask command** — inline input linking to `/dashboard/ask`

### Recommendation generation

The Morning Brief generates a fresh AI recommendation on page load via `GET /owner/brief`. This calls `callHaiku()` with the Context Package. Response time target: < 3 seconds. If the AI call fails, a static fallback recommendation is shown.

### Empty states by product status

| State | Prompt |
|---|---|
| No product | "Add your first app" → /products/new |
| Product + intake incomplete | "Complete your setup" → resume intake |
| Intake complete, no strategy | "Generate strategy" → strategy page |
| Full data | Full Morning Brief |

---

## Consequences

- `/dashboard` is now a redirect (2-line file)
- Morning Brief is the TTFU (time to first useful) page after login
- Metrics are secondary — available in Results, not the home screen
- Founders who bookmark `/dashboard` land on the Brief
